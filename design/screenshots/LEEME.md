# Capturas de referencia

Coloque aquí las imágenes PNG (o el PDF) exportadas desde el lienzo de diseño en claude.ai, una por pantalla, con el mismo nombre del archivo `.dc.html` (por ejemplo `Main.png`, `ProyectoSolar.png`, `Mobile.png`).

Claude Code las usará para comparar visualmente lo que construye contra el diseño aprobado.
