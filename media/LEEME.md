# Fotografías reales

Coloque aquí las fotografías reales que entregue la Fundación (staff, oficinas, proyectos, lote / dron).
`npm run dev` y `npm run build` generan automáticamente sus versiones optimizadas en `public/images/`.

- Formatos: JPG, PNG o WebP, idealmente de 2000 px de ancho o más.
- Nombres en minúsculas, sin tildes ni espacios (por ejemplo `staff-jesus-enrique-archila.jpg`, `oficina-1.jpg`).
- Luego se referencian en `src/content/` como `/images/<nombre>.jpg`.

No usar retratos generados ni imágenes sin autorización de la Fundación.
